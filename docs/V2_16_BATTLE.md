# v2.16：独立したEVA戦闘画面と都市描画

v2.15 `1e9d5effffa6a555dd7c7f26de1da408afde11b3`を継承します。既存のキャラクター・兵装・施設画像とEVA描画CSSは変更していません。追加した街並みはSVG/Three.jsの図形で、既存画像を差し替えません。

## 戦闘の入口と手順

ホームの「EVA戦闘専用画面」から独立した主要画面へ進みます。既存の「使徒監視」で接近を受信した場合や、使徒警報から対象画面を開いた場合も、この画面に接続します。

- **交戦**：相手と残存戦力、選択兵装、現在の担当機、次の一操作。通常の共通ヘッダー・下部ナビ・重複警報は専用画面内では省き、ホームと警報確認を専用ヘッダーに置きます。
- **担当機**：零号機・初号機・弐号機、機体状態、同期・給電、出撃審議の三基の賛否。担当変更で既存の承認は失効します。
- **使徒監視**：サキエル・シャムシェル・ラミエルの選択、特性と対処方針、接近の受信。
- **記録**：作戦結果と直近の実際の戦闘記録、作戦終了・復旧の確認。

格納中なら「発進準備」→「MAGI出撃審議」→「射出」→「外部給電」の順です。その後は選択兵装に応じて「解析」→「接近・A.T.展開・中和」、または「特別送電・充填」→「現ターン承認」→**武器名付きの攻撃**へ案内します。操作ごとに消費と敵の行動有無を表示します。準備・承認・給電を無条件に完了する自動戦闘ではありません。

平常な機体なら、格納から撃破まで専用画面内で操作できます。停電・通信断、MAGI保守、侵入、保安の保留、機体の回収・整備が必要な場合は、原因となる既存の担当画面へ案内します。保存は既存のバックアップ・トランザクションを通し、失敗した準備・武器変更を確定しません。選択兵装、担当機、作戦状態・履歴は既存の保存を共有します。

旧戦術指揮、EVA、MAGI、匿名対象の訓練は保持しています。従来の`mission/engagement`も互換経路として残し、新しい操作入口は`battle/engage`を使います。専用画面の4区画はURL・戻る/進む・再読込に対応します。

## 都市・兵装ビル

添付の砲塔ビル、装甲外装、斜めの外装材・庇、青い窓面、高層街の手前の住宅・電線を、新しい模式図に反映しました。公式の正確な配置・寸法ではありません。

「都市インフラ → 市街眺望」を追加。従来の2.5D地図にも外装と砲塔の追加レイヤーを置きます。兵装の配備可否、損傷色、街区収容は既存の都市状態に連動します。旧施設・迎撃武器の固定図はそのままです。

交戦画面ではThree.js r160の**実際のInstancedMesh**を使用。高層棟・窓面・外装材・住宅・屋根・砲身を207部品、6バッチにまとめ、地面を含め7ドローコールで描画します。都市の収容に伴う各インスタンスの高さと位置はAnime.jsの補間へ接続。WebGL非対応・コンテキスト喪失・省電力設定時はSVGへ切り替え、操作や戦闘条件を維持します。

GPUコンテキストは遅延生成の1つだけ。画面外・非表示では描画せず、状態変更や補間がある場合だけ共通スケジューラーで更新します。実際の端末性能を保証する値ではありません。

## Anime.jsの指定4項目

| 項目 | 適用 |
| --- | --- |
| Easings | 専用パネルに`eases.out(3)`、街区収容に`cubicBezier(.22,.68,.2,1)`、実際の命中に`outExpo` |
| engine.speed | 設定 → 補間・速度。0.5× / 1× / 1.5×を保存。演出だけを変更し、敵ターン・業務・通信・内部電源時間は変更しない |
| Three.js instanced meshes | 公式`getInstances`/`commitChanges`の数値位置・スケール部分をMITに基づき移植し、実際のInstancedMeshの行列へ反映 |
| composition | パネルは`replace`、単一の所有者が更新するインスタンス群は`none`、命中時の一時的な反動・発光は`blend` |

Anime.jsの独立RAFは引き続き無効。共通演出で最大6補間、単発100～800ms、非表示・画面外・低モーションでは終状態にして停止します。速度変更で業務や戦闘が早送りになることはありません。

数値アダプターは公式Three.jsアダプター全体ではありません。material/色/TSL/BatchedMesh/回転の拡張は取り込まず、現在使用する位置・スケールだけを通常のオブジェクト補間へ接続しています。ライブラリ本体は未改変のローカル配布物、Anime.jsとThree.jsのMIT全文を単体ScriptableコードとZIPに含めます。

小型`NERV_COMMAND_v2_16_STARTER.js`による導入・チェックサム検証・オフラインキャッシュと6ウィジェットを維持します。実機Scriptable/WebKitとFPS・メモリ・電池、実API・位置・気象通信は別途検証が必要です。
