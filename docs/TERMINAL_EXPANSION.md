# 管制端末・地下施設・職員業務の拡張

2026-10-17。再開点は `feature/nerv-visual-command` / `5f37075c6bff73d4e58a8e84b371923e3f2608ca`、作業ツリーに既存変更はありませんでした。

## 固定するEVA描画

今後も `assets/eva_units_redrawn.png`、`src/styles/eva.css`、`src/styles/command-visuals.css` の描画を維持します。旧基準のハッシュと照合する回帰を追加しました。今回の素材生成に三機は含めず、描画シートを上書き・再加工していません。

新しい `assets/command_world_atlas.png` は1536×1024、上半分が地下空洞・懸垂都市・湖・ピラミッド型本部、下半分が格納式迎撃砲です。既存機体の輪郭線・セル塗りを参考に画像生成した独自の背景で、公式素材・厳密な設定図ではありません。CSSで1回だけ埋め込み、起動・施設・兵装・操作結果で共有します。

## 起動・地下施設・兵装

- 起動：機関名の大きな文字、区分線、斜線、保存済みのMAGI/EVA状態、ローカル端末の識別を表示。架空のネットワーク診断を待たせず、開始・省略をすぐ操作できます。
- 都市インフラ → 本部・地下施設：健全性・主電源・通信・防護装甲をゲーム状態から表示します。
- 都市インフラ → 兵装監視：西/中央/東の選択、施設健全性、砲台・電力の状態を表示します。配備に連動して装甲扉を開閉し、地図の砲身も展開します。本部の地図記号はピラミッド形状です。
- 兵装・電力・修理の一時表示も共通の背景を使用します。MAGIの決議や固定EVA描画には重ねません。

走査線・照準収束・起動計器・扉の移動はCSSで行います。表示の動きは状態を変更せず、同じ状態の再描画では操作演出を再始動しません。アプリ/OSの低モーション、非表示時の停止を維持します。

## 搭乗者監視

EVA → 搭乗者監視。綾波レイ・碇シンジ・惣流アスカの対象機を選び、待機・搭乗準備・作戦参加・緊急回収待機・休息/整備連携、同期率、神経接続、給電を確認できます。選択機は機体監視と共通です。状態は既存の機体状態から導き、実際の医療情報や心拍を捏造しません。

## 職員通信から業務へ

表示中のランダム通信はホームを含む8画面に届きます。通知はページ内の追従する領域へ表示し、展開/折り畳み/閉じるに対応。画面移動やフォーカスの強制変更は行いません。通信履歴から後で受命することもできます。ホーム本体は引き続き移動ボタン・発令中警報のみです。

職員支援 → 受命・勤務評価：

1. 業務依頼を受命（同時3件まで）。
2. 対象画面の実際の操作を行う。
3. 作業確認後に完了報告し、勤務評価10PTを1度だけ記録。

業務は4種です。搭乗者確認は依頼された機体の確認が必要。本部確認は系統表示の確認操作、当直点検は5項目すべてのチェックと照合、引継ぎは受命後の新規登録が必要です。既存の「完了」表示だけで自動達成しません。期限・不在ペナルティはなく、戦闘XP・資材・気象は変更しません。

保存先は `personnel.dispatch`。受命状態、確認/報告時刻、勤務評価・完了累計、二重報告を防ぐIDを保存します。変更前バックアップと保存成功を待って反映し、保存失敗では受命・確認・評価を確定しません。警報復旧・再読込・旧保存の未知の項目を保持します。未完了の受命を履歴上限で削除しません。

## ウィジェットと画面分割

ホーム3サイズ・ロック画面3サイズの計6種を維持し、Scriptableのネイティブなスタック、等幅文字、帯、グラデーションで構成します。保存済みの警戒・都市状態・受命・搭乗者・勤務評価をサイズ別に表示します。ウィジェットから位置情報や通信を取得せず、未知の値は未取得とします。更新予定はOSへの依頼で、指定時刻の更新や実機レイアウトを保証しません。

既存35区画に本部・兵装・搭乗者・受命の4区画を追加し、8主要画面・39区画に分割しました。URL・戻る・再読込で各区画を復元できます。画面見本・検証結果は [VALIDATION.md](VALIDATION.md) を参照してください。
