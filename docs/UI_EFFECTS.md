# 機能選択ホーム・視覚/音響効果の更新

> これは前版の改修記録です。現在のボタンのみのホーム・警報復旧・MAGI・戦術は [職員向け操作ガイド](STAFF_GUIDE.md) を参照してください。

添付参考画像から、黒地・細いアンバー構造線・シアン/緑の信号・幾何学的な軌道表示・赤い大型警報という視覚的な要素を参照しました。参考画像内の火山/降灰表示や文言を新機能として取り込んでいません。作品画像・音源の追加ダウンロードもありません。

- ホーム：気象、都市インフラ、EVA、戦術/作戦、MAGI、日常ツール、設定へ進む7ボタンを一覧表示。元の管制状況・訓練・履歴は「管制状況・訓練・履歴」を開いて使えます。8画面と既存の相互ナビゲーションは維持しています。
- 視覚/動的演出：SVGのネットワーク球面、軌道とノード、低速の走査光、画面遷移、押下フィードバックを追加。新しい装飾には架空の実測値を表示せず、実際の保存状態から機能ボタンの状況を更新します。アニメーションOFF・OSの動き軽減では新演出も停止します。
- 大型警報：主電源停止、通信断、EVA内部電源喪失、都市防衛の敵性反応、作戦進行に連動。優先順位はこの順です。全ページ共通のスクロール追従パネルを表示し、対象ページへ移動できます。状態を解除・変更する機能は追加していません。「SIMULATION / 架空の訓練警報」を常に明示しています。実際の防災警報とは連携していません。
- 音響：操作・選択・承認・警告・警報・走査・出撃・拒否・完了を複数の発振器と音程変化で合成。短い有限長の音で、同時発音数と連続発音を制限し、出力にコンプレッサーを通します。自作合成音で、作品音源や警報放送は使用しません。描画し直すたびに警報音を繰り返しません。
- 音設定：初期値は従来どおりOFF。音量スライダーと試聴ボタンを追加。OFFにすると再生中の音も停止し、画面をバックグラウンドに移す際も停止します。音量は既存のprefsに任意の `soundVolume` を追加して保存し、古い保存に項目がなければ55%とします。他の保存データは変更しません。

表示拡張は `src/browser/terminal-effects.js` と `src/styles/terminal-effects.css`、合成音は `src/browser/sound.js` に分離しています。UI・音設定の変更を含む生成物は、元のv2.7成果物とは意図的に異なります。元のハッシュ資料は履歴として残し、状態・EVA・MAGI・作戦・訓練・戦術・都市防衛など12モジュールは旧コミットから変更されていないことをハッシュでも検査します。

検証コマンドは `python3 scripts/test.py`。追加の `tests/qa_terminal_browser.py` は7つの遷移、旧ホーム訓練、大型警報と優先順位、動き軽減、実際のChromium Web Audioの発音スケジュール、ミュート・音量保存・警報の重複再生防止を検証します。従来の都市防衛・作戦・保存・A.T.フィールド・3画面幅検証も実行します。

iPhone Scriptable/WebKitの実機での表示・音量・消音スイッチ・音の開始制限・バックグラウンド復帰と、実際の外部気象/地図通信は別途確認が必要です。Chromiumの発振器テストは、実機での聴感やスピーカー出力を保証しません。

2026-10-17のクラウド検証では、既存の状態テスト12件、ウィジェット6種類と追加APIモック、ビルド5件、配布リンク4件、ブラウザ15件（既存8件＋追加7件）を実行しています。画面幅は320/390/430px。ホーム・大型警報のキャプチャも `test-results/command-*.png` に保存しています。

配布時は `python3 scripts/copy_link.py` でGitHub上のブランチが今回のコミットを含むこと、生成物に未コミット差分がないこと、ビルドと一致することを確認し、コミット指定のScriptableコードリンクを生成します。未送信時は終了コード1で停止し、古いコードのリンクを生成しません。ローカルの作業パスをダウンロードリンクとして扱いません。
