## API会話

Scriptableで「メッセージ → AI設定 → 接続先・モデル・APIキーを設定」を開きます。既定は `https://api.openai.com/v1/responses`、`gpt-4.1-mini`。利用可能なモデルに変更できます。HTTPSの `/responses` または `/chat/completions` で終わる公開接続先に対応。カスタムプロバイダーは対応モデル・JSON出力形式を確認してください。

ネイティブの安全なキー入力欄を使います。空欄なら既存キーを維持。最後に送信先とモデルを表示し、「保存してAIをON」または「保存のみ / OFF」を選びます。キーは `nerv.command.ai.key`、設定は `nerv.command.ai.config` のKeychain項目だけに保存。HTML、保存JSON、WebViewブリッジ、ログにはキーを渡しません。キーをチャットやソースへ書く必要はありません。

ON時、通常勤務のユーザー発言に限り、選択相手の人格・知識範囲・公開状態・最新12メッセージ・記憶を設定先へ送ります。警戒・戦闘・非常、操作依頼、制限情報、自発通信は既存のオフライン処理を優先します。API利用料金やデータ取扱いは選んだプロバイダーの条件に従います。Responsesでは `store:false` を指定します。

ネイティブ通信は同時1件、タイムアウト12秒。WebView側は15秒で待機を打ち切ります。返答は320文字以内のJSONに制限し、担当画面確認の提案4種だけを許可。AIは内部状態を変更せず、業務を完了した扱いにもなりません。設定・状況が変化した返答は破棄し、未設定・OFF・障害・不正応答時はオフラインへ復帰します。API待ちでも保存や別画面の操作を妨げません。

課金につながる送信の試行記録を先に保存します。再起動時に送信済みか不明な要求を再送せず、オフラインで返信を完結。受信保存が失敗した場合は同じ返答を端末内キャッシュから再試行し、重複表示を防ぎます。一般ブラウザのプレビューはオフラインのみです。

## 保安シナリオ

原作の組織・役割を参考にした**独自の模擬事案**です。実際の侵入検知や公式の事件再現ではありません。

| 系統 | 照合対象 |
| --- | --- |
| 本部への侵入者検知 | 入退館証、監視映像、通行許可 |
| 整備指令の偽装疑惑 | 署名、送電履歴、当直引継ぎ |
| 監査回線・文書改ざん疑惑 | 封印、原本との差異、回線認証 |

30秒の共通世界更新に接続。状況連動ONでは最初の6更新後に発生し、解決後10更新で次の系統へ進みます。電源・通信が利用できない間は新規受付を保留。三系統が循環し、正規手続きの誤検知だった場合と実際の不一致がある場合を切り替えます。同じ冷却異常だけに依存しません。

案件を受領し、異なる証拠を2種類以上確認して解析を依頼。次の更新で照合結果が届きます。3種類目も確認可能です。一時保留、認証確認、上級職員への上申を選び、冬月副司令系統へ正式報告します。証拠1種類以上なら不確定要素を残した早期上申も可能。最終判断は上級職員が行い、担当職員に万能の発令権を与えません。

未保留のまま8更新を経過、または不一致の証拠で通行・転送を許可すると、記録整合性18・部署間確認8が低下し、在庫があれば予備部材1を使用。一案件につき一度だけ適用します。緊急上申で2更新後に引継ぎ。正規の案件を不要に保留した場合は部署間確認5が低下します。得点ランキングや戦闘報酬ではありません。

失敗中・偽装指令の照合後は通常のMAGI承認と戦闘実行を保留し、古い承認を失効。侵入対処中・冷却系統の復旧承認待ち・停電中は解析を止めます。警報の全系統クリアで案件を消すことはできません。共通状態をホーム、MAGI、通信、警報、オフラインウィジェットへ反映します。

`world.security`は独立スキーマ1。未処理1件、履歴6件を上限に保存し、既存の世界履歴・部署連絡にも記録します。未知の将来スキーマは保持して停止。共通世界の離席補完は既存どおり最大12更新＝6分で、無制限のバックグラウンド処理は行いません。

## 映像と負荷

- Spatial Grid：都市施設の健全性に連動する座標面。眺望と保安配置図に使用。
- Conic Portal：起動・発進中のリング。固定EVAの前面を覆わず、実際のシーケンスに重ねる。
- Wave Field：MAGI解析・侵入圧、EVA接続状態・シンクロ率を使った波面。
- Layered Parallax：固定ジオフロント画像に前景の管制線を重ね、ポインター移動で小さな奥行きを付ける。

指定サイトは現在の環境から403で取得できなかったため、ユーザー指定の4効果名をもとにした独自実装です。サイトの実コードや見本を取得・複製したとは主張しません。

Canvasは既存の共通スケジューラーへ登録し、登録上限12、画面可視性・DPR・品質予算・低モーションを共有。新しい常駐タイマーを画面ごとに増やしません。従来の666/WebGLを維持。CSSは主にtransform/opacityを使い、非表示時に停止します。実測したiPhoneの60fpsを保証するものではありません。

兵装図と新顔はWeb調査・ユーザー添付を参考にした新規イラスト。元の固定画像は再圧縮せず、新しいWebP二枚だけを追加し、HTMLへ各一回埋め込みます。大きなコードをコピーする必要はなく、小型STARTERを継続使用します。起動版の取得先は本体のコミットに固定し、SHA-256も照合するため、後日のブランチ更新で別の本体を実行しません。
