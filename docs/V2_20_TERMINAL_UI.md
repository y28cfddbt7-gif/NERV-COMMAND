# v2.20 / NERV管制端末UI

v2.19の保存・戦闘・MAGIエンジンを継承し、表示と画面間移動を改修。人物・EVA・使徒・施設・兵装・市街の原画像と保護済みEVA描画CSSは変更しない。

## 武器の透過

`assets/armaments_v214.webp` のRGBは固定したまま使う。背景除去ツールで作成した別の1774×887px RGBAアトラス `armaments_alpha_v220.webp` の**アルファだけ**を、同じ表示倍率・同じ切出し位置のCSS mask / -webkit-maskへ適用。生成結果のRGBで武器を描き直さない。持ち手、トリガーの内側、武器間の背景を抜き、黒い金属や輪郭は残す。装備資料・拡大表示・戦闘準備・兵装選択が同じルールを使う。

原本と歴史的ハッシュfixtureは維持。背景除去ツールのPNG出力を全RGBA画素が一致するロスレスWebPへ変換し、追加マスクは773,194bytes（約36%削減）。CSS変数で一度だけ埋め込み、標準/接頭辞の両指定でBase64を重複させない。導入は従来の約13KB STARTERと検証済み本体キャッシュを使い、大容量画像の再コピーは不要。マスク非対応環境では元画像の表示が残る。

## 共通の情報設計

- 黒に近い青灰色のパネルを基調に、選択・実行はアンバー、通常データは青緑、警報は赤。強い画面全体の走査線を取り除き、文字と固定画像の輪郭を優先。
- 操作説明は日本語システム書体、識別コード/数値は等幅、MAGI/警告の大見出しは従来の明朝系。新しい外部フォントやCDNは追加しない。
- ホームは職員業務/各管制の機能一覧を維持。大きな装飾ダッシュボードを追加せず、識別番号・目的・現在状態・矢印を持つ横長の選択行へ再構成。
- 下部はホーム・都市管制・戦闘・MAGI・通信の5項目。320pxでも各ボタン44px以上を確保。他の機能はホームと共通メニューから移動。
- 共通ヘッダーに機能名と選択中の区画を表示。どこからでも「機能一覧」を開ける。全12機能を検索でき、電源/機体/666などの別名にも対応。現在位置を強調。戦闘とMAGI主画面は没入用の短いヘッダー内へ入口を統合。
- メニューはフォーカスを閉じ込め、背面をinertにし、Escape/閉じる/背面タップで閉じる。元のスクロール禁止状態を復元し、Escapeでは呼出し元へフォーカスを戻す。該当なしも表示。ナビゲーションは既存のURL/履歴処理を利用し、発進未承認なら共通戦闘の承認画面へ誘導する。
- 区画タブはスクロール時も上部に残す。入力16px・ピンチズーム許可・明瞭なフォーカス枠によりiPhoneでの入力/拡大を支援。

## 維持する機能

2AP戦闘と手動照準、実給電、EVA単独勝利、固定街並み、MAGI三基と6系統の異常対応、職員業務、通信/AI設定、施設運用、警報確認/復旧、6種ウィジェット、保存互換性を維持。新UIは世界状態を書き換えず、ルート変更も既存のNERV_MOBILEへ渡す。追加のRAF/タイマー/世界更新/ネットワーク要求なし。既存の共通スケジューラ・低モーション・非表示停止を維持する。

## 調査と限界

2026-10-20にBingでEvangelion/NERVの画面・警告・タイポグラフィを検索した。検索は200だが、結果は作品一般情報が中心で、専門的なUI仕様の根拠には使わない。公式 `https://www.evangelion.co.jp/` はトンネル403、`https://wiki.evageeks.org/Magi` は526で本文を取得できなかった。既存のユーザー資料とTV系列の管制・三人格・工業的配置を継承し、公式画面の完全再現や公式手順とは表記しない。新しい人物設定やゲーム規則は追加していない。

Chromium/Scriptable APIモックによる検証とiPhone実機の結果は区別する。物理iPhoneのScriptable/WebKit/タッチ、FPS/メモリ/電池、実APIと気象通信は未検証。結果は `docs/VALIDATION.md`、`handoff/V220_VALIDATION_LOG.txt` を参照。
