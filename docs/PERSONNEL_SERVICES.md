# 職員証・通信・行動選択の継続改修

2026-10-17。EVA三機の素材・描画CSS・運用ロジックを維持し、既存33区画に職員証と通信を追加しました。8主要画面・35区画です。ホームは移動ボタンと発令中警報のみです。

## 職員証

職員支援の「職員証」で表示名・所属を登録し、「職員証を提示」で表裏を表示できます。閉じる/Escapeで元のボタンへ戻り、Tab/Shift+Tabはダイアログ内を移動します。固定の架空職員番号と当直状況を表示し、権限やゲーム能力は付与しません。実名の入力は不要です。

カードは既存の色に合わせた独自の文字・幾何学レイアウトです。今回の会話には元の「4枚目」の画像が添付されていないため、その画像を確認・再現したとは扱いません。外部の公式ロゴ・画像・音源を新規に取得していません。

## 館内放送・職員通信

職員支援の「館内通信」で手動受信でき、最新12件の内容・時刻・受領状況を保存します。ランダム通信は初期ON、表示中のみ90〜180秒間隔。同じ画面で停止できます。非表示・離脱時は停止し、戻ったら新しい間隔から再開します。不在中の通信をまとめて受信しません。

端末内で生成する架空の業務連絡です。敵・気象・資材・任務・当直記録を変更しません。外部通信・バックグラウンド通知・読み上げは行いません。受信音も効果音ONと音量設定に従います。

## 行動選択

戦術指揮の「行動を選択」から、分類 → 指令 → 実行前確認へ進みます。

- 戦術の次の指示：現在の作戦段階に対応する操作。
- 検知・状況解析：敵性反応の検知、波形解析。
- 施設・電力管理：選択施設の装甲・砲台・送電・修理。
- 関連管制：EVA発進管制、MAGI審議または侵入対処、戦域マップへ。

対象施設・防衛電力・資材・予備送電、消費/効果、未達条件を確認します。閲覧・戻る・閉じるでは状態を変更しません。状況が変わった場合は表示を更新し、再確認まで発令しません。実行には既存ボタンの処理を使用し、元の直接操作も維持しています。

## 操作音と保存

既存の承認・警告・発進音を優先し、ハンドラーとフォーム送信を待って無音だった操作にだけタップ音を補います。効果音OFF・非表示では再生せず、既存の音量・発音上限を維持します。

追加保存先は `personnel.profile`、`personnel.messages`、`prefs.staffComms`。変更前バックアップを確認し、保存完了後に反映します。失敗時は登録・受領・受信・設定変更を確定しません。当直・点検・引継ぎ・未知の項目を維持し、警報復旧でも職員証と通信履歴を残します。

別系統v2.8の `personnel.name` / `department` / `feed`、`prefs.hqComms` も読み取り、元の項目とバックアップを保持します。新しい設定を明示した場合は新設定を優先します。

`src/browser/personnel-services.js`、`command-dispatch.js`、対応するCSS・UIを共通ビルドへ追加しました。全体検証は `python3 scripts/test.py`、追加回帰は `tests/qa_personnel_services_browser.py` です。[最新検証結果](VALIDATION.md)と[画面見本](../handoff/previews/README.md)を参照してください。
