# v2.17 / 手動戦術盤・給電復帰・Canvas市街

既存の固定画像、EVA描画CSS、施設・都市兵装の画像、全12画面・98区画・11通信相手を維持。新規戦闘の操作と街並みの表示方式を変更します。保存は従来のバックアップ・永続化・失敗時ロールバックを共用します。

## 操作

ホームの「EVA戦闘専用画面」→「使徒監視」で対象を受信。格納状態なら発進準備、実際のMAGI三基の出撃審議、射出を行います。既存の作戦を引き継ぐ場合は「現在の作戦を戦術操作へ移行」を明示的に選択します。対象HP、都市資源、損傷をリセットしません。

出撃後は「次の手順」ボタンでは戦いません。

1. 「対象解析」でコアを特定する。
2. 機体を指で隣接区画へドラッグする。赤い区画は敵の**次の攻撃予告**。敵は移動前に狙った区画を攻撃するため、位置取りによって回避できる。
3. 遮蔽区画では被害が軽減される。「防御・1手」はA.T.防御で一撃を大きく軽減する。通常のA.T.展開とは別の行動。
4. ナイフ・パレットは近接してA.T.展開→中和。上部のコアに触れて照準を記録し、「装備武器で攻撃」。照準外なら外れ、弾・電力・敵ターンを消費する。
5. ラミエルにはポジトロンを選ぶ。外部給電、解析68以上、二段階充填、都市電力40が必要。足りない電力は予備枠を消費する「補助送電」で補う。「狙撃姿勢・1手」は敵の行動と引き換えに許容照準範囲を広げる。
6. 攻撃時は既存のMAGI戦術審議を実行し、実際に2基以上が賛成した場合だけ発射する。勝利後は記録画面へ。都市援護は初期状態で待機し、必要な場合だけ明示許可する。

キーボードでは戦術盤にフォーカスし、M→矢印→Enterで移動、A→矢印→Enterで照準。Escで取り消し。

## 給電の修正

- 電源喪失状態から、主電源・通信が正常ならアンビリカルを再接続してDEPLOYEDへ復帰できる。内部電源を無料で補充しない。
- 接続済み外部給電があれば、内部電源0秒でもA.T.と武器を使用できる。
- 通常武器に外部給電を強制しない。ポジトロンの高出力送電条件は維持。
- **手動戦術モードだけ**、思考中は攻撃担当機の内部電源時計を停止。敵の1行動あたり10秒＋既存の行動コストを消費する。戦闘終了後とほかの機体・従来戦闘の実時間消費と32秒の敵ターンは維持。
- 内部電源、外部接続、都市電力を別々に表示する。演出速度は資源消費や世界時刻を変更しない。

## 描画・負荷

市街眺望と都市地図はCanvas2D。戦闘背景は従来のローカルThree.js r160、利用不可・低品質・コンテキスト喪失時はCanvas2D。**街並みのSVGは表示しない**。従来の地図SVGは既存モデル・ID互換のため非表示で保持するが、表示・タップ・機体マーカーは新しいCanvas/HTMLを使用。固定の都市兵装イラスト等は保護したまま。

装甲ビルの収容・ガラス面・外装・住宅・電線・多連装砲塔と施設損傷を共通状態に反映。模式配置であり、地理的に正確な市街ではない。

戦術盤は実際の移動に伴うAnime.js補間、斬撃、パレット弾道、陽電子ビーム、命中火花、敵の反撃/回避を描画する。保存成功後だけ射撃演出を出す。低モーションでは静止した攻撃跡とダメージ表示。NERV_FXの第4フックを共用し、独立RAFを追加しない。短い演出のみ再描画し、非表示・画面外で停止。Threeの1コンテキスト・DPR上限・dirty描画を維持。

## 保存互換・範囲

`evaCombat.tactical` schema1に対象ケース・担当機・位置・照準・攻撃予告・命中/回避記録・援護設定を保存する。機体健全性は既存の部位損傷を引き継ぎ、回収後の整備・明示復旧でのみリセット。未知の将来schemaは上書きせず停止。壊れた座標は操作を停止し、バックアップ付き復旧を案内。単にページを開いただけで旧データを移行/初期化しない。旧戦闘APIからの接近や射撃による手動照準の迂回も防ぐ。

敵の区画予告、遮蔽、健全性、照準許容半径、ターン制限・10秒消費等は本アプリ独自のシミュレーション規則。原作の確定仕様とはしていない。

導入は小型 `NERV_COMMAND_v2_17_STARTER.js` を使用する。大きい本体を毎回コピペしない。HTTPSでチェックサムを照合して取得し、保存・バックアップ・既存キャッシュの制限を維持する。

iPhone実機のScriptable/WebKit、FPS・メモリ・電池・実タッチは未検証。Chromiumのポインター操作とネイティブAPIモックで検証する。
