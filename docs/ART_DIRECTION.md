# EVA描画と管制ビジュアル

2026-10-17。ユーザー添付の細身の機体線画、左右の神経系モニター、オレンジの計器・格子、走査線・緑の波形を参考に改修しました。機体素材の再描画はユーザーの明示的な依頼で実施しています。

## 機体素材

`assets/eva_units_redrawn.png` は画像生成ツールで描き直した1536×1024のRGBA素材です。三列に零号機・初号機・弐号機を置き、青/白、紫/緑、赤/橙の装甲と、頭部・目・角の違いを描いています。前後左右の資料図を背景に重ねる処理を除き、細い腰、長い脚、肩部、胸部・腹部装甲の輪郭を読み取れる大きさにしました。

生成ファイルには背景のRGB色も入っていますが、アルファは透過です。確認時は約101万画素がアルファ10未満でした。PNGを別途加工せず、三列をCSSの背景位置0/50/100%で表示します。一度埋め込んだシートを、機体監視・小型機構表示・SVGマップ内のマーカー・配置一覧で共有します。表示比率は1:2。元の画像ファイルはそのまま保管し、削除・上書きしていません。作品の公式設定画や公式素材として扱いません。

CSSの巨大なカスタムプロパティにはdata URLの展開制限があるため、通常の背景画像宣言を使用します。共通ビルドはCSS内のassetトークンも展開し、ブラウザとScriptableの同じHTMLへ画像を一度埋め込みます。実行時の機体画像ダウンロードは不要です。

## 情報と動き

- 操作結果・MAGI決議・次の行動は16px基準のSTATUS横流れ表示へ。停止/再開、キーボードフォーカスでの一時停止、低モーション時の全文折り返しに対応します。履歴は記録タブに保管します。
- 大型・小型のEVAは同じ新素材。A.T.フィールドの中心は機体と揃え、資料図の重なりや過剰な光彩を除きます。機体側面の波形はSYNCに応じた独自の模擬図です。
- 都市地図はゲーム状態から出撃機・電源喪失機・敵性反応を表示します。区画移動と敵接近を補間し、接触の波紋を表示。現実のGPS追跡ではありません。
- 装甲開閉・送電・修理・迎撃は操作に対応する機構表示へ。MAGI決議に防壁の共通小窓を重ねません。
- MAGI侵入対処は侵食率の円形計器、三基の健全/侵食表示、効果を明記した選択肢、横流れの物語状況で進めます。第拾参話の設定を参考にした独自シミュレーションであり、実際の外部通信・攻撃コードはありません。
- 画面移動のスプラッシュは約0.55秒。計器の回転、波形走査、マップ移動はCSS/SVGを使用し、低モーション設定で停止します。非表示画面のアニメーションも停止します。

## 導線

8つの主要画面を維持し、35区画に分割しています。EVAの各区画→戦域マップ、マップ機体→該当EVA、マップ→配置/迎撃、侵入警報→侵入対処、MAGI→出撃/戦術という経路を持ちます。URL・戻る・再読込でも対象区画を復元します。侵入/機体配置の新しい保存項目を使用する前に、専用の非上書きバックアップを作成します。

iPhoneのScriptable/WebKit実機、実音響、実際の位置情報・気象/地図サービスとの通信は別途検証が必要です。

職員証・通信・指令確認の追加UIは [PERSONNEL_SERVICES.md](PERSONNEL_SERVICES.md) と [追加画面見本](../handoff/previews/README.md) を参照してください。EVA素材・描画CSSはこの拡張で変更していません。
