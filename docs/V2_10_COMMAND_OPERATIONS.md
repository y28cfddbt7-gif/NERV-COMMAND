# v2.10 — EVA直接戦闘・司令部・MAGI外部防御

基準はユーザー指定の `07f2242` を継承した v2.9 (`0a73d2f`) です。旧mainへ戻していません。参照版の53ファイル、EVA三機の透過シートと描画CSS、承認されたパイロット顔シートを変更せず、追加モジュールで拡張しています。

## 操作

ホームに **NERV司令部** を追加。9主要画面・49区画になりました。追加区画は発令所、第三新東京市、ジオフロント、被害状況、職員通信、EVA直接戦闘、EVA交戦指示、MAGI外部防御、666防御指示、兵装選択です。横タブ・URL・履歴・再読込で独立した画面を選べます。

### EVAだけで勝つ

司令部 → EVA直接戦闘。敵性反応を検知し、対象を解析します。攻撃担当機を選び、出撃管制へ進みます。従来どおり発進準備 → MAGI出撃承認 → 出撃が必要です。出撃後は直接戦闘へ戻り、A.T.を展開。機体点検・給電でアンビリカル接続もできます。

交戦指示で **接近を2回 → A.T.中和 → 現ターンのMAGI戦術承認 → ナイフ攻撃**。中和は続く2行動が有効。攻撃後は承認を再取得します。2回で倒せなければ再中和して攻撃。ライフルも中和中は有効打を与えます。敵A.T.が健在なら射撃不可と理由を表示し、中和を先に行います。弾倉は1作戦6発。都市武装は一切配備しなくても、三機とも三種類の敵に勝利できます。

接近・中和・攻撃は都市電力を使用し、未給電機は内部電源も消費します。敵が生存すれば既存の都市ターンが1回進み、敵の接近・施設攻撃・未給電の追加32秒消費が発生します。外部給電中は内部電源を温存します。撃破時は既存の勝利・資材・経験値・進行中の任務完了判定を使い、二重報酬を防ぎます。機体・通信・電源・解析・侵入状態・承認の未達条件を表示します。

既存の陽電子砲支援ルートも維持しています。従来はそのPHASE・充電・照準条件に依存する支援射撃しかなく、通常武器を選べませんでした。追加ルートは陽電子砲用の充電や照準ロックを要求しません。

### 都市武装

都市インフラ → 兵装選択。3地上区画ごとに機関砲か誘導弾を選択し、資材20で配備。誘導弾は機関砲の1.4倍の火力と追加電力2を使用。防衛方針、解析、MAGI戦術票、施設損傷、給電も反映します。ターン予測と実処理は同じ `defenseForecast` を使います。健全性25未満の兵装は停止します。これらの数値は独自ゲームルールです。

### 666プロテクト

MAGIシステム → 外部防御 / 666。監視区画から外部ハッキング訓練を開始し、「666防御指示」区画で操作します。開始すると、通常審議とEVA攻撃が停止し、既存承認が失効します。

- 経路解析：演算資源12、解析+50、三基の侵入圧+16/+14/+12。
- 選択コアの隔離：資源10、そのコア-35、他二基+10。対象を明示して選ぶため当て推量ではありません。
- 666構築：資源30、解析100かつ各侵入圧90未満が必要。
- 遮断維持：資源8、全コア-30。3回維持で成功、経験値25。成功後は通常審議を再申請。
- 通常再起動：資源8、外部経路を閉じないため全コア+25、構築済み666も解除。危険を事前表示。

基本の成功経路は解析2回→構築→維持3回で資源22残。隔離を組み込む経路も成立します。2コアの侵入圧100、または必要な最低資源8を割ると失敗。警報確認の明示的クリアで復旧できます。時間経過だけでは侵入も敵ターンも進みません。数値・3回維持・報酬はアプリ独自です。

第拾参話型の適応侵食は従来の別区画に維持。そちらの外部隔離表示から666表記を外し、CASPERによる進化経路対処を666の効能と混同しないようにしました。外部侵入と適応侵食は同時開始できません。

### 司令部

発令所の多層司令卓、地上の兵装ビル、地下のジオフロントを追加描画。地上3区画と地下本部のゲーム内HP・停電を連動表示。被害状況から該当区画の修復に移れます。

葛城ミサト、赤木リツコ、伊吹マヤ、日向マコト、青葉シゲルの顔をWeb資料で調べ、新規のイラストにしました。既存パイロット画像は変更していません。平常・戦闘・被害・侵入で報告内容が変わり、手動受信と受領記録が可能。館内通信ONなら入室時に40%の確率でランダム受信し、60秒間は自動受信を抑制。非表示時と通信OFF時は自動受信しません。台詞は公式引用ではなく独自作成です。直近12件を保存します。

発令所には状態連動のWebGL投影を重ねています。GPUが使えない場合も背景描画を維持。非表示・別画面では描画ループを停止、低モーション時は静止表示。既存EVAの形やパイロットの顔にエフェクトを重ねて描き換えません。

## 保存・配布

6種のiPhoneウィジェットも、保存された外部MAGI侵入中は警戒表示となり、封じ込め後は解除します。実時間の侵入処理や外部通信は行いません。

既存の保存キーとScriptableの保存JSON名を維持。新規項目は `evaCombat`、`magi.externalDefense`、`cityArmament`、`headquarters`。読み込むだけでは進行を初期化せず、未知項目と既存履歴を保存。追加機能の最初の変更前に既存の非上書きバックアップを使い、保存失敗時は指示前へ復元します。明示的な警報クリアでは外部防御の成功/失敗累計と通信記録も保持します。

単体配布は `NERV_COMMAND_v2_10_SCRIPTABLE.js`。追加画像はWebP圧縮し、同一シートをCSSに1回だけ埋め込みます。元の固定画像は再圧縮・変更しません。巨大コードや画像のbase64をチャット本文へ貼らず、検証済みGitHubコードリンクで提供します。
