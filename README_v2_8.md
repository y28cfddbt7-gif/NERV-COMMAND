# NERV COMMAND v2.8 — PERSONNEL & COMMAND

既存v2.7の戦術・保存データ・EVAビジュアルを引き継ぎ、職員支援と行動選択を拡張しました。非公式ファン作品のローカルシミュレーターです。

## 使い方

- **ホーム → 職員証**、または **ツール → 職員支援室 → 職員証を提示**。表裏を切り替えできます。表示名・所属は職員支援室で編集し端末内に保存します。階級は既存のXPから表示し、新しい権限・ゲーム効果は付与しません。職員番号は架空の固定表示です。
- **管制 → 次の行動を選択**。分類 → 指令 → 条件確認 → 実行の3階層。現在の施設、電力、資材、条件不足を確認できます。確認段階では状態を変更しません。既存の実行処理とゲーム条件を使用します。「クイック操作」から元の直接操作も利用できます。
- **ツール → 館内放送・職員通信**。手動受信と受領確認に対応。最新12件を保存します。ランダム通信は表示中のみ約65〜140秒間隔、設定から停止できます。アプリを閉じた後に通知はしません。
- **設定 → 効果音**をONにすると、従来無音だった操作にも電子音を補います。既存の承認・警告音を優先し、二重発音を避けます。
- **設定 → 館内放送の読み上げ**は初期OFF。効果音ON時、対応端末の日本語音声で館内放送のみ読み上げます。音声が使えない場合も文字ログを利用できます。iPhone上の実際の音声・割り込み挙動は未検証です。

放送・通信・職員証・戦闘はすべて架空です。通信により実気象・公的警報やゲーム資材が変わることはありません。参考添付画像は取得できず、公式サイトも環境のネットワーク制限で参照できなかったため、既存の配色を使った独自レイアウトです。外部の画像・ロゴ・音源は追加していません。

## 開発・配布

Python 3.12、Node 24を使用。ブラウザテストにはPython Playwrightと`/usr/bin/chromium`を使用します。このクラウド環境には導入済みです。

```sh
python3 scripts/build.py
python3 scripts/test.py
python3 scripts/build.py --release
python3 -m http.server 8000 --bind 127.0.0.1
```

作業ディレクトリはこのリポジトリのルート。ビルドはPython標準ライブラリだけで動作し、絶対パスや外部通信を必要としません。`--check`は生成済みファイルとソースの不一致を検出します。ZIPの内容・タイムスタンプは再生成可能です。

- `src/core.js`: 既存の状態管理・画面・戦術ロジック。元の閉包を維持。
- `src/personnel.js`: 同じ状態と保存処理を使用する職員支援・通信・行動選択・操作音。
- `src/base.css`: 既存のスタイルをそのまま保持。
- `src/personnel.css`: 職員支援等の追加表現。EVA表示・A.T.フィールドのスタイルは変更しません。
- `src/browser.html`: ビルド用HTML。既存の機体画像・埋め込みリソースを保持。
- `src/scriptable.js`: ネイティブ保存・ブリッジ・ウィジェット用ラッパー。
- `app.js`、`styles.css`、`index.html`、`NERV_COMMAND_v2_8_SCRIPTABLE.js`: 生成物。直接編集せず`src/`を変更して再生成します。
- `NERV_COMMAND_v2_7_SCRIPTABLE.js`: 元のv2.7配布物を保存。
- `dist/NERV_COMMAND_v2_8.zip`: ブラウザ版、Scriptable版、コピー用テキスト、画像、利用説明を含む配布ZIP。

iPhoneのScriptableで新規スクリプトにv2.8の`.js`またはZIP内の`COPY_PASTE.txt`全文を貼り付けて実行します。旧版を残してください。初回移行時、Scriptableでは`nerv_command_v2_state_pre_v2_8_backup.json`、ブラウザでは`nerv-command-v2-pre-v28`キーに旧保存データを退避し、既存バックアップを上書きしません。同じv2保存先を継続使用します。

## 検証範囲

`scripts/test.py`は生成物整合性、既存状態管理12件、旧・新Scriptableの各6種ウィジェットモック、Chromiumの追加10件を実行します。追加検証には保存互換性、職員証の表裏とフォーカス、行動実行と前提条件、通信保存・受領、ランダム受信の停止、二重操作音防止、読み上げ条件、320/390/430px・8画面、全3機のA.T.フィールド中心位置を含みます。

外部通信はブラウザ検証時に遮断します。実気象・地図・レーダー取得、iPhoneのScriptable/WebKit、実際のスピーカー出力・読み上げは別途実機検証が必要です。
