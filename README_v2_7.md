# NERV COMMAND TERMINAL v2.7 / TACTICAL DEFENSE NETWORK

第3新東京市の防衛運用を中心にした、非公式のファン制作・ローカル戦略シミュレーター。**実際の防災警報や軍事運用を示すものではありません。** v2.6 のMAGI・EVA・作戦・実気象・地図・ツールを継承しています。

## インストール

1. iPhoneでScriptableの新規スクリプトを作成します。
2. `python3 scripts/build.py` で生成される `dist/NERV_COMMAND_v2_7_COPY_PASTE.txt` **全文**をコピーして貼り付けます（配布ZIP内では直下にあります）。ルートの `NERV_COMMAND_v2_7_SCRIPTABLE.js` も同じコードです。
3. 起動後、下部の **管制** を開きます。都市防衛盤が先頭に表示されます。
4. 初回起動時に共通の `nerv_command_v2_state.json` を使用。既存の保存データがある場合、別ファイル `nerv_command_v2_state_pre_v2_7_backup.json` にコピーを作る処理を追加しました。既に存在するバックアップは上書きしません。上書き防止のため旧バージョンのスクリプトは残してください。

**未検証**: iPhoneのScriptable実機/WebKit挙動、および気象・地図データの実ネットワーク取得。ブラウザ版はHTMLファイルの同梱デモです。

## 新しい作戦サイクル

- **管制**: `新規敵性反応` → 波形解析 → 2.5D地図の西防壁/中央兵装/東迎撃区/ジオフロントから施設を選択 → 装甲・砲台・電力・修理を選択。
- **MAGI**: 対象の波形解析34%以上で戦術審議。審議は各ターン更新制。適合した多数決が迎撃砲の効率を高めます。侵入トレースとノード隔離のミニゲームも追加。
- **EVA**: 既存の運用画面で出撃、必要ならアンビリカルケーブルを接続。未接続で作戦時間を進めると攻撃担当機の内部電源を追加消費します（ゲーム独自ルール）。
- **作戦**: v2.6のMAGI出撃承認、蓄電、照準を満たすと、都市防衛盤からEVA支援射撃が可能。
- **ターン**: 防衛盤で `作戦時間を進める` を押すごとに敵が接近し、迎撃砲が発砲。接近すると施設に損害が発生。
- **戦後**: 勝敗と施設損傷を保存。次のシナリオでも損傷は残るため、資材の配分と修復が必要です。

## 数値は独自設計

敵のHP、施設健全性、レーダー接近、送電量、部材価格、MAGI戦術評価、階級/XPなどはすべて独自のゲームパラメータです。作品の公式設定値ではありません。架空の敵性反応は匿名の3パターン。作品に存在する特定の使徒の設定・外観・行動をそのまま再現しているわけではありません。

## 互換性

v2.6の保存状態を読み込み、`defense` の初期値を補完します。ホーム/気象/管制/EVA/MAGI/作戦/ツール/設定の8画面を維持。ナビに機能を増やして圧迫する代わりに既存「管制」の上に防衛戦術盤を配置し、EVA/MAGI/作戦とのリンクを追加しています。
